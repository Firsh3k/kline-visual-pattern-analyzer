# K线形态量化分析工具

基于250日K线数据，自动识别8种高可靠性经典形态（4种上升 + 4种下降），计算底部信号分/顶部信号分/推荐度指数，标注关键点位并解读形成原因。

**Python脚本与在线网页应用算法100%一致，可用于数据回测。**

## 8种形态

### 上升形态（找买点）

| 形态 | 可靠性 | 说明 |
|------|--------|------|
| 均线多头 | 78% | MA5>MA10>MA20>MA60，主升浪 |
| W底 | 82% | 双底不创新低，突破颈线 |
| 头肩底 | 85% | 左肩-头-右肩，突破颈线 |
| 平台突破 | 80% | 横盘整理后放量突破 |

### 下降形态（找卖点/止盈）

| 形态 | 可靠性 | 说明 |
|------|--------|------|
| 均线空头 | 80% | MA5<MA10<MA20<MA60，下跌趋势 |
| M头 | 83% | 双顶，跌破颈线 |
| 头肩顶 | 86% | 左肩-头-右肩，跌破颈线 |
| 平台破位 | 81% | 横盘后放量跌破 |

## 推荐度评分系统

**0-100分，A/B/C/D/E五级，S级风险警示**

| 维度 | 分值范围 | 说明 |
|------|---------|------|
| 形态匹配度 | 0-100 | 基础分 |
| 形态可靠性加成 | +0~+10 | 头肩底1.1倍、平台突破1.05倍 |
| 当前阶段加成 | -15~+15 | 已突破+15、突破前夜+12、主升浪+12、回踩+8 |
| 量价配合 | -8~+16 | 放量+6、量价齐升+6、价涨量缩-4 |
| 均线状态 | +0~+18 | 完美多头+10、价格>MA20+4、价格>MA60+4 |
| 多形态共振 | +5 | 第二名形态≥50分 |
| 见顶风险扣分 | -5~-25 | 下降形态≥70扣25、≥50扣15 |
| MACD背离 | -12~+12 | 底背离+6~12、顶背离-6~12 |
| 量价背离 | -8~+8 | 底部量价背离+8、顶部-8 |
| 颈线确认 | +5~+10 | 确认天数+放量倍数+回抽确认 |
| RSI/KDJ信号 | -15~+15 | 超卖金叉+15、超买死叉-15 |
| 布林带突破 | -12~+12 | 收口突破上轨+12、破下轨-12 |
| 相对强度 | -10~+10 | 个股20日涨跌 vs 大盘20日涨跌 |
| 周线共振 | -8~+8 | 周线均线多空与日线一致 |

**等级**：S级风险警示（下降形态≥60）/ A≥85 / B≥70 / C≥55 / D≥40 / E<40

**三重确认**：推荐度≥70 且 底部信号≥50 且 顶部信号<50

## 使用方法

### V6 本机一键运行（不需要服务器）

在国内网络的电脑上运行，行情和同花顺板块成分股都由这台电脑直接拉取。需要 Python 3.10+ 和 Node.js 20+。

```bash
python scripts/run_local.py          # 打开 http://localhost:8080，用户名 owner
python scripts/run_local.py --lan    # 同一 Wi-Fi 的手机也能访问（终端会打印手机地址）
```

第一次运行会自动安装依赖，并让你设置登录密码（保存在 `var/local/`，不进 Git）。按 Ctrl+C 停止。
在云服务器等不能交互输入密码的环境，用环境变量给出密码：`KLINE_LOGIN_PASSWORD='至少12位' python scripts/run_local.py --lan --no-browser`。这种方式是 http 明文访问，适合先试用；长期对公网开放请用 `deploy/docker-compose.yml` 并加 HTTPS。
个股页输入代码即实时分析；扫描页选“同花顺板块代码”，输入如 `886032`，会自动拉取成分股并扫描。


### 方式一：Python脚本（推荐，自动拉数据）

```bash
# 单股快速分析（自动拉取新浪财经250日K线）
python3 scripts/analyze_stock.py 002436 兴森科技

# 输出JSON：当前形态、底部/顶部信号分、推荐度评级、关键点位、均线/MACD/RSI
```

### 方式二：在线网页应用

直接用浏览器打开 `kline_analyzer.html`，或访问已部署的在线应用。

功能：
- 输入股票代码自动拉取数据
- 250日+60日双图，形态标注（颈线/左右肩/双底等）
- 点位解读（形成原因+判断理由+市场含义）
- 自选股池持久化管理
- 17个预置板块批量扫描
- 大盘环境判断 + 个股当前阶段 + 形态可靠性

### 方式三：作为Skill使用

将 `skill/` 目录复制到 `~/.doubao/agent_mode/workspace/.user_skills/` 下，即可在其他任务中调用：

```
kline-pattern-analyzer skill 触发条件：
- 分析K线形态
- 判断股票趋势阶段
- 识别底部/顶部信号
- 计算形态匹配度
- 复盘报告中的形态判断
```

## 数据来源

- **K线数据**：新浪财经公开接口（250日日线，前复权）
- **股票名称**：腾讯行情接口
- **大盘环境**：上证指数250日数据
- **板块成分股**：同花顺iFinD概念板块

## 注意事项

- 北交所股票（920开头）新浪接口不支持，建议过滤
- ST股投资价值低，建议过滤
- 形态分析是技术面参考，不构成投资建议
- 下降形态信号强时，即使上升形态匹配度高也应谨慎（S级警示）
- 平台突破/破位需配合放量确认，假突破概率约20%
