# Kline Visual Pattern Analyzer V5.0

**Release type:** Architecture foundation  
**PAIOS Pilot:** PILOT-001  
**Related:** BUG-010 (#12), ENG-003 (#24), PILOT-001 (#28)

## Purpose

V5.0 establishes the first canonical algorithm-core primitive for the project: a deterministic swing-pivot detector under `core/`.

The objective is to migrate future pattern recognition away from broad-window extrema toward explicit ordered market structure such as:

- W bottom: `L1 -> H1 -> L2 -> breakout`
- M top: `H1 -> L1 -> H2 -> breakdown`
- Head & Shoulders: ordered shoulder/head/neckline pivots

## What ships in V5.0

- `core/pivots.py`: canonical confirmed swing-high/swing-low detector.
- `core/__init__.py`: canonical-core package entry point.
- `tests/test_pivots.py`: deterministic offline tests.
- CI gate for pivot syntax, regression tests and critical-file integrity.
- Explicit pivot semantics and limitations.

## Pivot semantics

A candle is a confirmed swing high only when its `high` is strictly greater than all highs in the configured left and right confirmation windows.

A candle is a confirmed swing low only when its `low` is strictly lower than all lows in both confirmation windows.

Rules:

1. `left >= 1` and `right >= 1`.
2. Boundary candles without complete left/right confirmation are excluded.
3. Equal-price plateaus are rejected rather than arbitrarily selecting one candle.
4. A single wide-range candle that qualifies as both swing high and swing low is rejected as ambiguous.
5. Output is chronological and uses the stable schema: `index`, `type`, `price`, `date`.
6. `day` is preferred as the date source, with `date` accepted as fallback.

## Important non-change

**V5.0 does not yet route production W-bottom, M-top or Head-and-Shoulders scoring through the new pivot engine.**

Therefore this foundation release is intentionally designed not to change current recommendation scores, trading outputs, Web/Python parity results, or existing pattern classifications.

Production migration will occur in later V5 increments only after fixture coverage, before/after false-positive analysis and independent QA.

## Rollback

The V5.0 foundation is additive. Rollback consists of reverting the V5 commits or removing `core/`, `tests/test_pivots.py`, the V5 CI additions and the `VERSION` file. Existing production pattern code remains intact.
