# 形态超额收益验证报告

数据集：FIR-13 校准数据（73 只有信号的股票，信号日 2024-05 ~ 2026-09）。样本外切分日 2025-10-01。基准往返成本 0.30%。

## 结论（T+20，震荡市 × 平台突破/头肩底/W底）
**一句话：原报告里的高收益主要来自「震荡市这几段时间整个股票池都在涨」；扣除成本、对比同期随机买入后，剩下的超额收益很小，统计上与 0 无法区分，样本内外也不一致。**

- 全样本 676 笔：平均毛收益 +3.12%，扣费后 +2.81%；同日股票池等权随机买入 +2.40%。
- **扣费后超额（相对同日随机买入）+0.41%**，按月聚类 95% 置信区间 [-0.80%, +1.65%]（18 个月），不显著；跑赢基准的笔数占比 40.2%。
- 相对「同股、同为震荡市的随机日期买入」的择时超额 +1.29%，置信区间 [-1.61%, +4.71%]。
- 样本内（< 2025-10-01）283 笔，扣费后超额 -0.89% [-2.76%, +1.66%]，不显著；样本外（≥ 2025-10-01）318 笔，扣费后超额 +0.84% [-0.55%, +2.25%]，不显著。
- 注意：震荡市在这段时间只出现在少数几个时间段（见按月分布），信号成簇出现，有效独立样本远少于笔数。

## 方法
- **入场/退出**：信号日收盘价买入，持有 h 个交易日后收盘价卖出（与 FIR-13 回测一致）。同股同日多个形态合并为一笔。
- **B1 同日随机买入**：信号当天在股票池其余股票中等权随机买入的期望收益，代表「同期随便买」的机会成本；视为被动持有，不扣增量成本。
- **B2 同股随机日期**：同一只股票、同一大盘环境、同一时间段（样本内/外）内随机日期买入的期望收益，衡量形态的择时价值；双方都交易，成本抵消，按毛收益比较。
- **交易成本**：佣金万2.5/边 + 印花税0.05%（卖出）+ 过户费0.001%/边 + 滑点0.10%/边，往返 0.30%。另做低/高成本敏感性。
- **样本外切分**：信号日 ≥ 2025-10-01 为样本外；样本内信号若持有期跨过切分日则剔除（purge），B2 的随机日期也限制在同一时间段内。形态和分组规则在两段完全相同，没有在样本内调参。
- **置信区间**：按信号所在自然月做聚类自助法（2000 次），因为同月信号高度相关。样本内/外各只有 6~10 个月，区间只是粗略参考；少于 6 个月不做判断。
- **价格来源（重要局限）**：本次运行环境无法访问行情接口，基准所需的全股票池日K由数据集内的价格点重建（信号日入场价 + 各 horizon 收盘价，按交易日历定位），≤3 个交易日的缺口做对数线性插值。
  价格点 26,466 个，冲突丢弃 264 个，插值 13,409 个。
  用仓库内真实日K（6 只，2026-05~09）检验 T+20 收益：430 对样本，绝对误差中位数 0.00 个百分点，90 分位 2.08；其中端点含插值的 209 对，误差中位数 1.02、90 分位 2.76 个百分点。插值误差是随机噪声，会放大单笔基准误差，但对上千笔的均值影响很小。
  在能联网的机器上先跑 `scripts/run_calibration.py` 生成 K 线缓存，再跑本脚本即可自动改用真实日K。
