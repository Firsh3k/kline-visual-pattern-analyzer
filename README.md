# K线形态识别扫描器

基于 OHLCV 日线数据，自动识别 6 种经典上涨形态，生成带标注的 K 线图和交互式 HTML 报告。

## 工具结构

```
kline_pattern_scanner/
├── pattern_scanner.py    # 主分析脚本（单只股票）
├── batch_scan.py         # 批量扫描脚本（多只股票汇总）
├── data/                 # K线数据目录（CSV格式）
│   ├── 600519.csv        # 示例：贵州茅台
│   └── 002594.csv        # 示例：比亚迪
├── output/               # 输出目录
│   ├── 600519_report.html
│   ├── 002594_report.html
│   ├── batch_scan_report.html
│   └── *.png             # K线图
└── README.md
```

## 六种上涨形态

| 形态 | 量化特征 | 对应场景 | 强度 |
|---|---|---|---|
| ① 均线多头突破 | MA5>MA10>MA20>MA60，收盘价突破20日新高，收阳 | 主升浪启动 | 强 |
| ② MACD零上金叉 | DIF上穿DEA，二者均在零轴上方 | 强势反弹/续涨 | 中强 |
| ③ 放量突破平台 | 突破20日高点，成交量>5日均量1.5倍，涨幅>3% | 盘整后启动 | 强 |
| ④ W底突破颈线 | 双底不创新低（第二底≥第一底97%），放量突破颈线 | 超跌反弹 | 中强 |
| ⑤ 回踩均线企稳 | 上升趋势中回调至MA20/60附近，收阳下影线，缩量 | 趋势中继买点 | 中 |
| ⑥ 均线粘合发散 | MA5/10/20/60前期纠缠（差值<3%），MA5上穿MA20发散，放量收阳 | 长期盘整后主升浪 | 强 |

## 使用方法

### 1. 获取K线数据

通过通达信 MCP 工具 `tdx_kline` 获取日线数据：

```
调用 mcp__tongdaxin_stock_quotes__tdx_kline
参数:
  code: "600519"        # 纯数字代码
  setcode: "1"          # 沪市=1，深市=0
  period: "4"           # 日线
  tqFlag: "1"           # 前复权
```

返回数据中提取 `Rows` 数组，保存为 CSV 格式，放入 `data/` 目录。

### 2. CSV数据格式

文件名用股票代码命名，如 `600519.csv`：

```csv
date,open,high,low,close,volume
20260511,1344.87,1344.87,1332.98,1333.31,57135.1
20260512,1333.98,1335.56,1322.48,1326.53,50837.43
...
```

- `date`: 日期，格式 YYYYMMDD
- `open/high/low/close`: 开高低收价格
- `volume`: 成交量

### 3. 单只股票分析

```bash
python3 pattern_scanner.py data/600519.csv 贵州茅台 600519
```

参数说明：
- 第1个参数：CSV文件路径
- 第2个参数：股票名称（可选，默认"贵州茅台"）
- 第3个参数：股票代码（可选，默认"600519"）

输出：
- `output/600519_chart.png` — 带形态标注的K线图
- `output/600519_report.html` — 交互式分析报告

### 4. 批量扫描

将多只股票的CSV放入 `data/` 目录，然后运行：

```bash
python3 batch_scan.py 10
```

参数 `10` 表示只关注最近10个交易日内的信号（可调整）。

输出：
- `output/batch_scan_report.html` — 批量扫描汇总报告
- 同时需要先对每只股票运行 `pattern_scanner.py` 生成个股报告

## 报告内容

单只股票HTML报告包含：
1. **最新行情概览** — 收盘价、涨跌幅、区间高低点
2. **当前技术状态** — 均线排列、MACD多空、量能状态
3. **K线走势图** — 蜡烛图+均线+成交量+MACD，形态信号用箭头和标签标注
4. **近期形态信号** — 最近5个信号的日期、类型、强度、描述和操作建议
5. **形态统计** — 全区间内各形态出现次数

## 技术说明

- **数据周期**：默认使用最近100个交易日（约5个月），足够计算MA60和识别中短期形态
- **复权方式**：建议使用前复权数据
- **均线参数**：MA5/MA10/MA20/MA60
- **MACD参数**：标准(12, 26, 9)
- **颜色规则**：A股习惯，红涨绿跌

## 注意事项

1. 本工具基于历史数据的技术形态量化识别，**不构成投资建议**
2. 技术形态存在失败可能，需结合基本面、市场环境综合判断
3. 形态识别参数（阈值）可在 `pattern_scanner.py` 中调整
4. 建议将工具作为**选股初筛**，命中后人工复核K线图再决策
5. 过往表现不代表未来收益，市场有风险，投资需谨慎
