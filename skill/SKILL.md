# K线形态分析器

## 核心能力

对单只或批量A股股票，基于250日K线数据进行量化形态识别：

- **8种形态识别**：4种上升（均线多头/W底/头肩底/平台突破）+ 4种下降（均线空头/M头/头肩顶/平台破位）
- **多空信号评分**：底部信号分(0-100) + 顶部信号分(0-100)，同时检测上升中见顶风险
- **推荐度指数**：0-100分，A/B/C/D/E五级，S级风险警示（下降形态≥60时触发）
- **关键点位标注**：颈线位、左肩/头/右肩、双底/双顶、平台上下沿等
- **点位解读**：每个关键点的形成原因、判断理由、市场含义
- **五大增强指标**：RSI/KDJ、布林带、相对强度、ATR动态止损、周线形态确认
- **三大增强信号**：MACD顶/底背离、量价背离（4种细分）、颈线确认度
- **大盘环境判断**：上证指数技术面评分，影响个股置信度
- **形态可靠性**：8种形态经典可靠性 + 完成度 + 综合置信度

> **v4.0 与网页端100%一致**：Python脚本(analyze_stock.py)与在线网页应用(app_17f40r564tw)使用完全相同的算法逻辑——相同的指标计算、相同的8形态检测规则、相同的推荐度评分公式、相同的评级标准。可用于数据回测。

## 数据获取

**K线数据**（浏览器端/脚本端通用）：
```
https://quotes.sina.cn/cn/api/jsonp_v2.php/{callback}/CN_MarketDataService.getKLineData?symbol={market}{code}&scale=240&ma=no&datalen=250
```
- 6开头股票 market=sh，0/3开头 market=sz
- 返回 day/open/high/low/close/volume JSONP格式

**股票名称**：`https://qt.gtimg.cn/q={market}{code}`（GBK编码，script标签加载）

**上证指数**：代码用 `sh000001`（注意000001会被误判为平安银行）

## 使用方式

### 方式一：Python脚本（批量/自动化场景）

**单股快速分析（推荐，自动拉取数据）**：
```bash
python3 scripts/analyze_stock.py <股票代码> [股票名称]
# 示例: python3 scripts/analyze_stock.py 002436 兴森科技
# 输出JSON：当前形态、底部/顶部信号分、推荐度评级、关键点位、均线/MACD/RSI
```

**完整分析（需先准备CSV，含图表生成）**：
```bash
python3 scripts/pattern_scanner.py <csv路径> <股票名称> <股票代码>
# CSV需包含 day/open/high/low/close/volume 列
# 输出：HTML报告+K线图+完整形态标注
```

**批量扫描**：
```bash
python3 scripts/batch_scan.py [--days N] [--data DIR] [--output DIR]
# -d/--days: 扫描最近N个交易日的信号（默认10）
# --data: 指定数据目录（默认自动向上查找data/目录）
# --output: 指定输出目录（默认data目录同级的output/）
# 输出：每只股票的推荐度排序表格
```

### 方式二：在线网页工具（交互式分析）

在线应用（含K线图可视化标注、形态知识库、自选股池、市场扫描）：
- app_id: app_17f40r564tw
- 支持输入股票代码自动拉取数据、250日+60日双图、点位标注解读、自选股持久化、17个预置板块批量扫描

### 方式三：嵌入其他任务（如每日复盘）

在选股/共振筛选后，对Top标的调用形态确认：
1. 拉取250日K线（新浪接口）
2. 计算MA5/10/20/60/250、MACD、RSI、KDJ、布林带、ATR
3. 运行8种形态检测算法
4. 输出：当前形态、底部信号分、顶部信号分、推荐度评级、关键点位
5. 筛选规则：推荐度≥70 且 底部信号≥50 且 顶部信号<50 → 标记"三重确认"

## 评分系统

**推荐度指数**（0-100）由以下维度加权计算（与网页端calcAttentionScore完全一致）：

| 维度 | 加分/扣分范围 | 说明 |
|------|-------------|------|
| 形态匹配度 | 0-100（基础分） | 最佳上升形态的匹配度 |
| 形态可靠性权重 | +0~+10 | 头肩底×1.1、平台突破×1.05 |
| 阶段加成 | -15~+15 | 已突破+15、突破前夜+12、主升浪+12、回踩+8、构建中+3、失败-15 |
| 量价配合 | -8~+16 | 放量+6、量价齐升+6、价涨量缩-4、价跌量增-4、量比>1.2+4 |
| 均线状态 | +0~+18 | 完美多头+10、短期多头+5、价格>MA20+4、价格>MA60+4 |
| 多形态共振 | +5 | 第二名形态≥50分时 |
| 见顶风险扣分 | -5~-25 | 下降形态≥70扣25、≥50扣15、≥35扣5 |
| MACD背离 | -12~+12 | 底背离+6~12、顶背离-6~12 |
| 量价背离 | -8~+8 | 底部量价背离+8、顶部量价背离-8、缩量止跌+8、放量滞涨-8 |
| 颈线确认 | +5~+10 | 确认天数+放量倍数+回抽确认 |
| RSI/KDJ信号 | -15~+15 | 超卖金叉+15、超买死叉-15 |
| 布林带突破 | -12~+12 | 收口突破上轨+12、收口破下轨-12 |
| 相对强度 | -10~+10 | 个股20日涨跌 vs 大盘20日涨跌 |
| 周线共振 | -8~+8 | 周线均线多空与日线一致 |

**等级**：
- S级风险警示：下降形态≥60（立即止盈止损）
- A级：≥85（强烈关注）
- B级：≥70（值得关注）
- C级：≥55（观察）
- D级：≥40（偏弱）
- E级：<40（回避）

**三重确认**：推荐度≥70 且 底部信号≥50 且 顶部信号<50

**形态经典可靠性**：头肩底85%、头肩顶86%、M头83%、W底82%、平台突破80%、平台破位81%、均线多头78%、均线空头80%

## 注意事项

- 北交所股票（920开头）新浪接口不支持，建议过滤
- ST股投资价值低，建议过滤
- 形态分析是技术面参考，不构成投资建议
- 下降形态信号强时，即使上升形态匹配度高也应谨慎（S级警示）
- 平台突破/破位需配合放量确认，假突破概率约20%

### v4.0（2026-10-01）— 与网页端100%对齐

**核心目标**：Python脚本与在线网页应用(app_17f40r564tw)使用完全相同的算法逻辑，可用于数据回测。

**修复的7处算法差异**：
1. RSI/KDJ信号：改为"RSI超卖/回升+KDJ金叉/K<30"组合判断（原简化版条件不同）
2. 布林带收口：改为"120日宽度百分位<25%"判断（原用"当前宽度<5日前×0.8"）
3. 量价分析：改为"近5日首尾涨跌+VMA5趋势"判断（原用"当日涨跌+当日量/VMA5"）
4. 大盘环境：改为完整10项指标评分（maBull/aboveMa20/ma20Up等），阈值75/60/45/30（原简化5项，阈值70/55/45/30）
5. MACD背离：改为用highs/lows找前后5天极值，阈值1.01/0.99，强度含DIF差异项（原用closes找前后3天，阈值0.98/1.02，无DIF项）
6. 量价背离：改为"近20日高低位+VMA5/VMA20比值"（原用"60日趋势+近5日量比"）
7. 颈线确认：改为"基础30+天数25/15+放量20/10+回抽25"评分（原用"天数×10+放量×30+回抽30"）

**已确认一致的模块**：数据获取、指标计算(MA/MACD/RSI/KDJ/BOLL/ATR)、8种形态检测、推荐度9项评分、五大增强指标、S/A/B/C/D/E评级、三重确认、形态可靠性、相对强度、ATR止损、周线共振。
