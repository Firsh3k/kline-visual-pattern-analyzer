🎯 假信号识别指南（提高交易成功率的核心）

🔴 假突破（买入假信号）迹象
  • 缩量突破：突破颈线时成交量未放大，资金不认可
  • 3天内回落：突破后3个交易日跌回颈线下方
  • 逆大盘：熊市/震荡偏弱环境中突破成功率仅25-30%
  • 板块不共振：个股涨但同板块其他股票不跟涨
  • MACD顶背离：价格创新高但MACD不创新高
  • 远离均线：突破时价格已偏离MA60超30%
🟢 假破位（卖出假信号）迹象
  • 缩量破位：跌破支撑时无量，无恐慌盘，多为主力洗盘
  • 快速拉回：1-3天内重新站上支撑位，典型"空头陷阱"
  • 逆大盘：牛市/震荡偏强环境中破位可能是洗盘
  • MACD底背离：价格创新低但MACD/RSI不创新低
  • 关键支撑位：破位位置正好在MA120/MA250或前期低点附近
  • 板块集体假破位：同板块多只股票同时破位，系统性洗盘
💡 辨别假信号的4大方法
1. 等待确认（最有效）
突破/破位后等3个交易日，真信号会站稳，假信号会快速回归
2. 量价验证
真突破=放量突破+缩量回踩不破；真破位=放量破位+反弹不过颈线
3. 多周期共振
日线+周线同方向胜率提升20%；日线信号+周线反方向=大概率假信号
4. 大盘环境适配
只在适配的环境下操作：牛市做突破，熊市做破位，逆环境信号打5折
📈 提高交易成功率的纪律
高胜率组合 = 高可靠形态（头肩底/顶85%+） + 适配大盘环境 + 量价配合 + 多周期共振
严格止损：买入后跌破颈线3%立即止损；卖出后站回颈线3%立即回补
仓位管理：单只不超过总仓位20%；盈亏比3:1，即使胜率50%也能赚钱
回测验证：用本工具的回测功能，系统性验证每种形态在不同环境下的真实胜率
