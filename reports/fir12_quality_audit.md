- 审查对象：8 个 v4_only + 4 个 v5_only cases（见 `data/v5_validation/results.json`）
- 审查日期：2026-10-04（数据截至 2026-09-30 收盘）
- 固定 rubric：4 个维度（结构 Pivot / 颈线合理 / geometry / 突破有效），逐例取证
- 方法：加载 `data/v5_validation/{code}.csv`，用 `SwingPivotEngine(left=5,right=5).detect_confirmed_only()` 取得 V5 已确认 pivot 集合，复算 V4-JS 移植（`scripts/v5_validation.py::v4js_detect`）的结构点索引/日期/价格，逐点比对
- **本报告不修改任何 pivot/pattern 参数**，仅做质量裁定

## 0. Rubric 与分类标准

### 4 个维度

| 维度 | 通过标准（✅） | 存疑（⚠️） | 不通过（❌） |
|---|---|---|---|
| D1 结构 Pivot | 形态关键头/肩/顶/底/颈线点均为 (5,5) 已确认 swing pivot | 部分关键点位已确认、其余未确认 | 关键头/肩/顶/底本身不是已确认 pivot，或肩/颈点缺失 |
| D2 颈线合理 | 颈线锚定已确认对立 pivot；当前价与颈线关系真实 | 颈线点已确认但外推到当前价偏离过大（>10%） | 颈线来自未确认点，或线性外推到无意义水平（高于头/低于底） |
| D3 geometry | H&S：头高于/低于肩 ≥3–5%，两肩价差 ≤20%；W/M：两腿价差 ≤5%，secondHigher/Lower 符合 | 头-肩价差 1–3%（勉强） | 头-肩价差 <1%（头不显著），或两腿价差 >5–10% |
| D4 突破有效 | 末根收盘明确越过颈线（bearish: 收盘 < nl；bullish: 收盘 > nl），量能配合（v5/v20>1.1） | 收盘在颈线 ±2–3% 内（接近未越） | 未越颈线即标 broken，或假突破/量能背离（v5/v20<0.9） |

### 分类

- **v4_only**：`valid_old_signal`（4 维度基本达标，V4 检出的是合理可操作信号）/ `low_quality_old_signal`（≥2 维度不达标）/ `ambiguous`（1 维存疑）
- **v5_only**：`valid_new_signal` / `low_quality_new_signal` / `ambiguous`

## 4. 结论

1. **raw recall 11/19=57.9% 的下降是合理的、有意的质量取舍。** 8 个 v4_only 全部为 low_quality_old_signal，根因一致：
   - V4 用 lookback=80 内全局极值当头/底，无右侧确认窗口；其中 6/8 的"肩/顶"在 (5,5) 确认窗口下不是已确认 swing pivot（距头/峰仅 3–5 根）；
   - 4/8 的 H&S 颈线被线性外推到无意义水平（600519→1397 高于头 1363；000858 hs_top→96.07 高于头 78.84；000858 hs_bottom→91.70；300750→182.54）；
   - 5/8 的头-肩价差 <2%（rubric 要求 ≥3–5%）；
   - Case 6（000858 hs_bottom）右肩=末根 K 线本身（未来函数），真实结构是 W 双底（V5 已正确检出为 both）。
2. **不需要 tune pivot/pattern 参数。** 没有发现 materially valid 的 V4 patterns 被丢失（valid_old_signal=0）。V5 用已确认 pivot 替换窗口极值、拒绝无确认肩/颈点，正是 FIR-12 杜绝未来函数的设计目标。
3. **V5 新检出质量**：1 valid（V2，failed_break 诚实标注）+ 2 ambiguous（V1/V3，未决形态）+ 1 low_quality（V4，002415 hs_bottom 在 0.82% 头肩价差上误触发）。该 low_quality 是 V5 自身的弱检出，**不属于"被丢失的 V4 信号"**，按硬约束不在本次 tune；可在后续 FIR 中考虑给 H&S 头肩价差加最小门槛（当前 `head < ls` 仅要求严格小于，无最小 % 闸门），记录为 follow-up。
4. **建议**：本 PR 可进入 code review。V5 的召回缺口已被逐例证明为"低质量 V4 伪信号被正确过滤"，而非有效信号丢失。
